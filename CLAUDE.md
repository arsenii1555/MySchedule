# «Пара» — розклад юрфаку ЛНУ

Веб-застосунок (PWA) для студентів юридичного факультету ЛНУ імені Івана Франка: студент обирає свою групу й бачить свої пари. Працює в Safari/Chrome на телефоні, додається на головний екран, працює офлайн. Хоститься на GitHub Pages: `https://arsenii1555.github.io/MySchedule/`.

Автор — студент 1 курсу (ЮРД-1Р), не програміст. Пояснюй зміни простою мовою, українською. Інтерфейс програми — лише українською.

## Принципи (не порушувати без прямого прохання)
- **Без бекенду, акаунтів і збору даних.** Вибір групи зберігається лише в `localStorage` телефона (ключ `para.v1`). Тому не потрібна політика конфіденційності — не додавай аналітику, трекери, сторонні запити.
- **Один файл сторінки, без фреймворків і збірщиків.** Чистий HTML/CSS/JS. Зовнішнє — лише Google Fonts (Golos Text, Unbounded, JetBrains Mono), із системними запасними шрифтами.
- **Розклад вбудований у сторінку** як JSON, щоб усе працювало офлайн.
- Світла й темна тема через CSS-токени в `:root` (+ `prefers-color-scheme`). Нові кольори — лише через токени.
- Мобільна ширина ~390px — основна. Безпечні зони iPhone (`env(safe-area-inset-*)`) враховано, не ламай їх.

## Структура
```
index.html, sw.js, manifest.webmanifest, *.png, .nojekyll   ← ЗІБРАНИЙ сайт (корінь = те, що віддає GitHub Pages)
src/
  app.html          ← ДЖЕРЕЛО сторінки (CSS+JS). Містить плейсхолдер /*DATA*/null і /*SW*/
  data/data.json    ← розклад, який вбудовується в сторінку
  data/parsed.json  ← сирий результат розбору PDF (з номерами сторінок _pg для звірки)
  pdf/k1..k4.pdf    ← офіційні PDF розкладів 1–4 курсів, 1 семестр 2026–2027
  parse.py          ← розбір PDF → data/parsed.json (pdfplumber, геометрія ліній таблиці)
  build_data.py     ← parsed.json → data.json (чистка, злиття однакових занять)
  build_site.py     ← app.html + data.json → index.html, sw.js, маніфест, іконки в корінь
  review.py         ← текстовий перегляд розібраних занять по сторінці PDF: `python3 review.py 2 1,2`
  dump.py           ← сирий дамп геометрії сторінки PDF для налагодження: `python3 dump.py 3 2`
  test_offline.py   ← Playwright: перевірка service worker і роботи офлайн
```
**Ніколи не редагуй `index.html` у корені вручну** — він генерується. Змінюй `src/app.html` (або дані) і перезбирай.

## Збірка
```bash
cd src
pip install pdfplumber pillow            # один раз
python3 parse.py && python3 build_data.py # лише якщо змінились PDF
python3 build_site.py                     # завжди після змін app.html або data.json → пише у корінь репо
```
`build_site.py` сам підставляє хеш версії в `sw.js`, тож телефони підтягнуть оновлення при наступному відкритті з інтернетом.

## Модель даних (`data.json`)
```js
{ updated, sem:{start,end}, ref:{mon:"2026-10-19", t:"z"},   // тиждень 19.10 = знаменник; парність рахується від нього
  times:{ "1":["08:30","09:50"], ... "7":["18:10","19:30"] },
  courses:[{ n:1, pdf, groups:["ЮРД-11",...], streams:[["ЮРД-11","ЮРД-12","ЮРД-13"],...], L:[ заняття ] }] }
```
Заняття `L[]`:
- `g` — масив груп, яким воно стоїть; `d` день 1–5; `p` номер пари; `s` предмет; `k` вид (лекція/практичне/лабораторне); `t` викладач; `r` аудиторія
- `w` — `"c"` чисельник, `"z"` знаменник, відсутнє = щотижня
- `sg` — підгрупа 1/2 (лабораторні ділять групу навпіл)
- `fl` — іноземна мова (`en`/`de`/`fr`): кілька викладачів в один час на весь потік, студент обирає свого
- `el` — вибіркова дисципліна (назва), `ct` — `ВНД` або `ДВВС`, `eg` — номер(и) групи вибіркової. Вибіркові спільні для всього курсу
- `time` — нестандартний час, напр. ОНС у НСК `["11:00","12:20"]`
- `s:"ДВВС"` без `el` — слот університетських ДВВС без деталей

Вибір студента (`localStorage`): `{c, g, sg, fl:"en:ас. Чорний В.В.", el:{"Військове право":2}, elSet:true}`.

## Як влаштований PDF (важливо для `parse.py`)
- Кожен потік (3 групи) — окрема таблиця; 1 курс — 1 сторінка на потік, 2–4 курси — 2 сторінки.
- Пара, поділена горизонтально: **верх = чисельник, низ = знаменник**. Порожня смужка зверху/знизу означає, що заняття лише в один тиждень.
- Клітинка на пів групи = підгрупа; клітинки, що не збігаються з межами груп, — іноземна мова (якщо предмет «Іноземна мова») або вибіркові.
- Вибіркові часто записані **повернутим текстом** у вузьких колонках; межі бувають пунктирними.
- Рядок пари може **переходити на наступну сторінку** (напр. 3 курс, четвер 1 пара): частина на першій сторінці = чисельник, продовження = знаменник.
- «ВАК» замість викладача = вакансія (показуємо «вакансія»).
- Після будь-якої зміни парсера звіряй результат `review.py` із зображенням сторінки (`pdftoppm -r 150 -png -f N -l N src/pdf/kX.pdf out`). Еталон: група ЮРД-1Р (сторінка 7 у k1) перевірена вручну.

## Відомі припущення (можуть бути неточні)
- Кінець семестру `sem.end` = 2026-12-31 (точної дати в PDF немає).
- Парність тижнів — від `ref` (19.10.2026 = знаменник).

## Перевірка перед здачею
1. `python3 build_site.py` без помилок.
2. Синтаксис JS: витягни останній `<script>` з `index.html` і `node --check`.
3. Відкрий `index.html` у браузері (або Playwright) на ширині 390px, світла й темна тема: вибір групи → «Сьогодні» → «Тиждень» → «Пошук» без помилок у консолі.
4. Для змін офлайн-логіки — `python3 test_offline.py`.

## Публікація
Закомітити зміни в `main` → GitHub Pages оновить сайт за 1–2 хв. Посилання не змінюється, поки не перейменовано репозиторій. `index.html` має лишатись у корені.
